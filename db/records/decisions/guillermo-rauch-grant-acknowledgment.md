compact "Grants and sponsors" section. Both link to https://github.com/rauchg.
The acknowledgment links directly to the official recipient list at
https://rauchg-oss-grants.vercel.app/.

## Evidence and attribution

[[sources/references/2026/09/2026-09-10-guillermo-rauch-grant-and-profile]]
preserves the official recipient-list entry, the personal grant terms from
the public announcement, and GitHub API metadata matching the name, account
and avatar. The program awarded Carlos Galarza a USD1,000 grant for Slotstream.

no payment-receipt claim or ongoing sponsorship commitment. The grant is
personal and unaffiliated with Vercel, so the acknowledgment names Guillermo
and uses his profile photo rather than a company logo.

## Photo provenance and maintenance

GitHub account `rauchg`, numeric user ID `13041`, supplies the avatar at
https://avatars.githubusercontent.com/u/13041?v=4. The README embeds that
GitHub-hosted image with a size parameter, explicit dimensions and descriptive
alternative text. The visible name remains readable if the image fails.
No image copy is added to the repository or represented as MIT-licensed artwork.
The remote photo can change when its owner updates his profile.

Keep the direct official award link as the public proof. This acknowledgment
is independent of GitHub Sponsors enrollment or the eventual payment route.
Update the attribution if Guillermo requests a change or the official sources
